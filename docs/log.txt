ID 开关

set "NINEYIN_PLAYER_IDENT=scene"   :: 玩家进场分配（缺省 fixed，恒 1-1）
set "NINEYIN_NPC_IDENT=scene"      :: NPC 走官服形态（缺省固定段 0x0E）
两个开关互相独立。只开玩家开关时，玩家序号会排在固定段 NPC 之后，不撞号。

需要你知道的
真机 A/B 还没做。建议先只开 NINEYIN_NPC_IDENT=scene，在烟雨庄确认 NPC 是 0x03xxxxxx 段且能交互，再单独开玩家开关。
数值不会和抓包完全一样。单人新手场景在 scenes.ini 里每个 member 一节，本仓取第一节（0x2C 段），抓包落在 member=16 那节（0x3D 段）；形态一致。
缺省可见的线上变化只有一处：0x0B[1:5] 从进程级计数变成连接 serial，0x04@0x21 从 0 变成同一个值。
