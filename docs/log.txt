脉络清楚了：

714.973 秒：服务端给玩家下发了一套任务技能——skill_musejuben_2/4/5/6/7/8/9 共 7 个（m141 + 系统提示 m1 "9491"）。

这套技能的伤害是 224~226（常规的长拳是 1~39），长拳 04 的 _4、_2 是范围技，_6/_7/_8 是锁定技，命中带击退。
看这套技能的完整施放流程，以及 m270 是什么消息。

任务技能的施放流程完整了，几个要点：
C2S m270 "skill_musejuben_2"                          ← 用 m270 施放，不是 m211
S2C m1[2,"9026"]                                      ← 玩家在空中：9000+26「此技能不能在空中使用」
C2S m270 ×N → m1[2,"9009"]                            ← 冷却中：9000+9（m270 施放会报错提示，m211 是静默）
S2C CurSkillID="skill_musejuben_2" → 冷却行 → MP → m20[玩家,"CS_jz_xytf03"]   ← 受理，动作用的是真实技能「逍遥腿法03」的动作

「musejuben」应该是「暮色剧本」——剧本/剧情实例专用的技能。看这套技能在 11-02 版本的表里怎么定义，和常规技能差在哪。

GM 训练木桩
参考端（9yin-go-server2）GM 面板的「训练木桩」移植到当前服，入口是 gm dummy <玩家> [血量|clear] [数量]，面板测试台加了「训练木桩」子页。
做法是运行时按官方木桩模板 mon_cclone_mz001 现合成一条摆放，物化、战斗、交互都走静态 NPC 那条链，只补了四处：对象号现分并登记、只对本人可见、CantAttack=1 不还手、死亡后不重生。
两个查数据才知道的点：客户端表里 RefreshTime=-1 是绝大多数怪的默认值，不能当「不重生」判据；本线普攻射程只有 2 米，参考端的前方 2.5 米在射程外，改成 1.8 米。
单测 11 条全过，全仓 72 包通过。exe 没重编部署，也没上真机；战斗假人（会还手的玩家造型）这次没做。



攻击后没有自动选中目标
原因是我选错了模板。照参考端取的 mon_cclone_mz001 在参考端数据里叫「蜃境木桩（一阶）」，但在当前客户端数据里是「测试木桩0豁免」——非敌对、不可杀死、不参与战斗。客户端按 ConfigID 查它自己的表，不把这种对象当可攻击目标，按攻击自然不会自动选中。
已换成新手村的官方练习木桩 funnpcborn003043（敌对、能打死、自己不攻击、固定不动）。带修复的 exe 已编进 build\，需要部署并重启服才生效；线上现在跑的还是旧模板。
服的输出只在它自己的控制台窗口里，我这边两种只读方式都被系统拒绝，日志看不到，所以这个结论是从客户端数据和参考端逆出的客户端判定规则推出来的，没有线上帧作证。如果换了模板还不行，在 env.server 里加一行 set "CAPTURE=1" 再重启，我就能直接看客户端发了什么。
