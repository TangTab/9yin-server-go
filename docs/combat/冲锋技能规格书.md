## 一、概念定界（最高优先级，勿再混淆）

**自走 ≠ 冲锋，两段分治：**

| 段 | 范围 | 职责 |
|---|---|---|
| 接近段 | 按压点 → 冲锋阈值（判距带）之前 | **客户端**：手动控制位移，或客户端设置「按下技能自动靠近」（自由操作模式+autopath_useskill）。两种手段同一段事。服务端不驱动、不分析 |
| 冲锋段 | 进判距带之后 | **技能本身**：c61 授予 → 客户端执行冲刺位移 → m212 到位申报。冲刺位移是 c61 指令的直接结果，与自走设置无关 |

服务端全程**零 0x21 驱动帧**；对客户端怎么走不做任何假设与补偿。

## 二、判距分带（§直收/受理分流的前提）

距离基准：单体锁定技=玩家上报/211 自报位到目标（211 自报目标坐标优先，服务端坐标兜底）；范围点地技=到点选平面点。

## 三、判断点消息（进带触发，技能4/技能5 定版）

- **单体锁定**：客户端接近段移动上报 **m15**（走/停流）与 **m220**（冲锋接近上报，进带那一刻的申报帧）；服务端在任一上报进带时授予 c61（官方 m220→c61 间隔 24~132ms）。
- **按压即带内（受理簇尾即授）**：211 按压点已在**同层地面带** (lo, hi] 内时，进带判定以按压自带位置在受理簇尾即刻完成（2026-11-17 真机定案：本服登录方言客户端无「按下即走」，站立按压零 m15/m220 上报，单等上报=地面带死；官服「3~5m 立即冲锋」、落尘「13m 受理即冲」均此形——技能4 #5 的 m220 只是同义的接近申报）。混层近距闸同在受理簇尾。**空中档不在此列**：空中授予维持 m220 驱动（技能5 穿云纵 state7 飞行中实证）。
- **范围点地**：**m211 按压本身就是判断点**（点坐标在按压里，无 m220 无接近段，c61+40ms）。
- **带外 stage 期不发 c61**（技能1.pcapng 定版：受理簇零 m24；c61 只在进带时下发——含上述按压即带内形态）。

## 四、c61 授予簇（单体锁定）

按下帧序（技能4.pcapng 20.194 空中授予逐帧 + 官服六样本）：

```
c61[dest,flag,动作] → CantMove=1 → CantParry=1 → CD 双行(0x11+0x13×4) →
MPRatio → MP →（空中 +QingGongPoint、+60ms m707[29]）→ [AOI 裸 c61 广播]
```

- **c61 载荷**：`m24[obj, 61, destX,destY,destZ, flag, 动作名]`。dest=目标身前 bind（bindDistance，缺省 1.5m）；flag=1 地面 G 类 `qg_fastrun_{W}h_01` / 2 空中 A 类 `qg_fastruning_s_{W}h_01`（方言表/覆盖可换）。动作名解析三级（2026-11-18 定版）：① skill_lock_data **逐技能块**（包内 HitAction 分块；含 15 个官方异武器档动画如 whjf02 剑技 5h，不可覆写）；② 缺行按**套路武器**构造（skill_new.UseLimit → skill_use_limit ItemType：101刀→1h…108短棍→8h，空中族 1h~8h 同表·动作库实测）；③ 兜底默认 2h。
- **dest.y 全档 = 目标 y + 1.0**（技能4 地面五样本 4.975 全带、技能5 高→低 0.68~1.08）；唯低→高空中档=目标平面本体（抬 1.0 会冲过平台面悬空）。
- **AOI 裸广播**：施法者的 c61 帧抄送同场景其它成员（跳过本人）——观察者不收私有簇、零位移流，远端渲染纯靠 c61（群战.pcapng）。
- **CD/MP/轻功在此结算**（commitRushDashCosts：MP/SP 硬闸、轻功点尽力扣不硬闸、个人/公共 CD 写入、currentSkill 簿记）。CantMove/CantParry=1 冲刺不可打断（官方同毫秒方言）。
- 空中受理标记：staging 时空中暂存补 `CurIsAirSkill=4`（紧随 CurSkillID）。

### 4.1 成对 0x21 冲刺同步条目（方言事实；默认关闭）

官方 c61 后 63~214ms 必发一条**本人** 0x21（技能4 地面 4/5 + 技能5 空中 4/6；例外=穿云纵打断/连按风暴样本）：

| 档 | 条目 | 槽位 |
|---|---|---|
| 地面单体 | 91B 双条目 | 同步条：dest=c61 dest xz、y=地面平面、s5=25(LandRushSpeed)、s6=-2π、s7=10.8、s8=9.9、intent=**0x4701**；空置回显：dest=按压位、s5=0、s6=0、s7=10.8、s8=9.9、intent=0xA0000700 |
| 地面点地 | 47B 单条目 | dest=c61 dest 完全一致、y=点选平面、s5=**35**、s6=-2π、s7=10.8、intent=0x4701 |
| 空中 | 47B 单条目 | dest=c61 dest 本体、s5=15(AirRushSpeed)、s6=-2π、s7=5.5、s8=9.9、intent=**0x4704** |

intent 高字节 0x47=skillrush 事件(0x71)态家族。**该条目=地面冲刺位移本体（2026-11-17 23:22 真机翻案，默认发）**：0x4701/0x4704 是 0x21 白名单里唯一 mover 逐帧自驱动的态；裸 c61 对地面档零位移（真机授予后客户端 state4 停一帧即恢复 state7 普通走路；v24「c61 受理即授予=六秒零位移」同证）——官方地面 4/5 样本 c61 后 63~214ms 必发此条即冲刺驱动。此前「客户端自行冲刺」系误判，「歪歪扭扭」=mover 与接近行走抢道（当时带界 5.0 授予过晚、驱动程长），带界 6.5 修正后待复测；观感异常走 `NINEYIN_RUSH_SYNC_PAIR=off` 回退。

| 出口 | 触发 | 动作 |
|---|---|---|
| **m212 到位申报（主通道）** | 客户端自报到位（尾值 1=冲刺/0=步行） | 落地簇（§5.1）锚=212 自报位；官方 27/27 m26=m212+39~78ms |

| 迟到 212 | pending 已消费但 dashIssued 残留 | 轻功还原 + 授予对清 0 + rush 标记复位（该轮唯一收尾） |

**212 三分**（有 pending 时）：距离基准=当前服务端 NPC 实时坐标。超走带（>max(GRushRange, castRange+1)）且冲刺已发=按到位申报释放；超走带未发冲刺=无条件落地续招（Java b 线方言，防客户端狂发 212 无响应）；走带内=正常落地。无 pending 212 官方零回应（仅位置收编）。

### 5.1 落地簇（resumePendingCastAt，f 冲刺落地 / b 步行落地双形态）

### 5.2 授予对/轻功还原组（取消、rearm、过期共用）

c61 已发（dashIssued）后任何收尾出口必须：空中档发**轻功终结符**（0x21 空置条目 speed=0/intent=0xA0000700/motion3=9.9，writeQinggongReleaseFrame）；CantMove/CantParry 清 0。漏发=「穿云纵后续有概率用不出」与玩家被冻两类真机病灶。

## 六、范围点地冲刺（issueAreaGroundRushDash）

c61（dest=点选平面点本体 +1.0、flag/动作随空/地档）+ AOI 广播；客户端自走冲刺；ETA=3D 距离/档速（地面 25+120ms / 空中 15+250ms）后落地簇：空中档补轻功终结符 → msg26 → 0x1F → msg337，锚=客户端当前上报位（缺省按压位；绝不写 dest）。调用方（skill_combat.go）以同 ETA 在终点**重放该 211**（Values[2..4]=地面点），届时 ≤3.5 走主施法直收=有动画的冲锋非瞬移。

## 八、受理簇（stageRushCast，暂存=桶②③④）

- 首发序：`[0x12 清扫] → CurSkillID=staged 技能 → [空中 +CurIsAirSkill=4] → CurSkillTarget → msg25[30000,'skill_pause'] → PauseSkill=技能 → m707[15] → 状态四连`。

## 九、移动上报处理（m15/m220）

- m15 全形态 idx3..5 恒为 x,y,z：位置收编（absorbClientPosition，场景权威坐标）+ noteClientReport（呆坐哨基准）+ JumpTimes 镜像。
- **JumpTimes 官方镜像**（技能4 62 帧定版）：起飞（地面→state6）授 1（三段跳 Buff 活跃授 2）；空中动作耗 0（腾空后 state6 再上行 >0.3m=二段跳，或腾空期 state7=空中水平段）；落地 state4/5 静默复位。不发=客户端空中配额耗尽永不复活。
- **回显方言**（echoPlayerMoveIntent，技能.pcapng §一）：寻路族（id 高 16 位 0xA000）与 WASD 族（0x0000/0x3000）的 state7/6/8 回显单条目 0x21（走帧 dest/角度/速度/朝向取上报槽；停帧 dest=上报位、角度=增量）；state5 跳跃不回显；走↔停迁移补状态四连；同态重发只回 0x21；手动格挡期整段静默。冲锋在途段（dash 已发）不回显。
- m220（4×f32）：位置收编 + noteClientReport → tryRushArrival 进带判定（§二/§三）。
