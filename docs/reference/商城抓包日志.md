## 2. 核心结论：商城 UI 是纯客户端本地

**证据链**（截图时刻 01:32:17，商城 UI 已完整展示商品/价格/页码）：

1. **C2S 全帧分类**（整个会话 415 帧）：
   - `0x18` ×120（12 字节周期心跳）
   - `0x0A` ×294（客户端记录/状态上报）
   - `0x09` ×1（客户端 ACK）
   - **没有任何「打开商城/拉取商品列表」语义的请求帧**（对比：官服拉列表类操作必有 0x1E/0x27 C2S TVarList 或 record 请求）。
2. **S2C 侧**：全会话 316 条 record-add 中，行数≥10 的全部是 rec=324（周围玩家外观表，世界同步期间下发）；无商城商品表。
3. **S2C custom msgID 目录**（447 条）中无商城列表推送；商城打开前后（01:31:17–01:32:17）S2C 只有世界同步（0x21/0x2C/0x2D/0x2E/0x28）与 msgID=294 时间同步。
4. **平台通道 6001** 解码确认为世界聊天/SNS：明文 JSON（`{"RoleInfo":...}`、`{"taskend":...}`）+ HTML 聊天富文本（`<a href="item,...">` 物品链接）+ 心跳 `0400000010ee1111` ↔ `0400000001ff0000`。与商城无关。

→ **私服实现商城时：商品配置（奇货铺/珍宝阁、时装/坐骑/百货页签、89金9折、限量限购、共2页）做进客户端本地数据即可，打开商城不需要服务端应答。**
