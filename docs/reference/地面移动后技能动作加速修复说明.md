# 地面移动后技能动作加速修复说明

## 结论

本问题已经于 2026-08-02 完成服务端修复，并由客户端实机确认：

- 刚进入场景时技能动作正常；
- 地面移动、后退并停下后再次施放技能，不再出现动作或画面加速；
- 不需要修改客户端 Lua、DLL 或资源包。

根因不是 NPC 加载、视野对象刷新，也不是两次技能 ID20 帧的字段不同，而是服务端缺失了现代客户端需要的视觉动作速度属性，并把一个百分比增量属性写成了错误的非中性值。

## 原始现象

修复前的稳定复现步骤：

1. 进入场景后原地施放技能，动作速度正常；
2. 在地面向后移动或快速移动，然后停下；
3. 再次施放相同技能；
4. 技能动作和部分画面表现明显加速；
5. 在空中移动时不容易触发。

服务端生成的两次 ID20 技能帧字段相同，因此问题不在单次技能帧的 ConfigID、目标、动作标志或末尾速度参数。

## 客户端证据

现代 `FxGameLogic.dll` 中 `0x11747700` 的属性回调会：

1. 查询玩家对象是否存在 `ActionSpeed`；
2. 读取 `ActionSpeed` 浮点值；
3. 将该值写入视觉角色的 `Speed`；
4. 同时写入关联 Actor2 对象的 `Speed`。

对应反汇编位于：

`E:\9yin-go-server2\artifacts\audit\fxgamelogic-motion-action-disasm.txt`

关键地址：

```text
0x11747710  查询 ActionSpeed 是否存在
0x1174772B  读取 ActionSpeed 浮点值
0x1174779E  visual role.Set("Speed", ActionSpeed)
0x117477B0  Actor2.Set("Speed", ActionSpeed)
```

而 `AddVisualRole` 创建视觉对象时，`MoveSpeed` 走的是另一条地面移动初始化路径。由此可以确定：

- `MoveSpeed` 管地面位移；
- `ActionSpeed` 管 Actor2 的可视动作速度；
- 两者不能使用同一个字段代替。

## 服务端原有错误

### 1. 没有协商和发送 ActionSpeed

旧服务端只发送了：

```text
MoveSpeed = 25
RunSpeed  = 25
SpeedRatio = 100
```

属性表中完全没有 `ActionSpeed`，所以客户端的原生 `ActionSpeed → Actor2 Speed` 回调无法获得服务端基准值。

地面移动状态机在“移动 → 停止”过程中会改变 Actor2 的内部运动/动作状态。由于没有 `ActionSpeed` 重新建立权威基准，相同的 ID20 技能帧可能在不同的 Actor2 状态下执行，表现为移动后技能加速。

### 2. SpeedRatio 的中性值写错

现代属性定义中，`SpeedRatio` 是百分比增量：

```text
0     = 不增不减
正数  = 加速
负数  = 减速
```

旧服务端把默认值和复活值设置为 `100`，相当于提供了 `+100%` 的加速增量；同时 `SetSpeedRatio` 又把所有负数强制截成 `0`，导致正常的减速效果也无法表达。

## 实际修复

### 1. 修正 SpeedRatio

文件：`internal/entity/actor.go`

- 新角色默认值由 `100` 改为 `0`；
- 复活后的值由 `100` 改为 `0`；
- 删除负数强制归零逻辑，允许服务端表达减速状态。

### 2. 增加 ActionSpeed 属性

文件：`cmd/protocol-probe/player_actor.go`

新增：

```go
defaultPlayerActionSpeed float32 = 1
propActionSpeed          uint16  = 237
```

这里的 `237` 是本地服务端 0x09 可见属性表中的顺序编号，不是硬编码猜测的官方固定编号。FxNet2 的 0x09 表只发送属性名称和类型，客户端按照表中顺序建立本次连接使用的属性编号。

`ActionSpeed=1.0` 被加入以下路径：

- 首次登录/场景重入的玩家 `0x0D PlayerAddObject`；
- 普通完整玩家状态 `0x10 ServerObjectProperty`；
- GM 修改 `MoveSpeed` 时，同时重申 `ActionSpeed=1.0`，避免移动速度调整后遗留 Actor2 全局速度状态。

### 3. 扩展现代属性表

文件：`cmd/protocol-probe/main.go`

在现有 `Weapon` 属性之后追加：

```go
FieldSpec{Index: 237, Name: "ActionSpeed", Type: WireFloat32}
```

属性表总数由 237 项变为 238 项。因为属性表必须在进场前通过 0x09 协商，所以部署后需要重新进入角色，旧连接无法热增加该字段。

## 已排除的错误方向

本问题不应再回到以下方向重复修改：

- NPC 加载数量或视野半径；
- NPC 0x0D/0x1F 加载生命周期；
- Buffer/Buff 图标同步；
- 同一技能 ID20 字段差异；
- 客户端 Lua 或 DLL 修改。

后续若再次出现动作速度异常，应优先检查玩家对象的 `ActionSpeed`、`SpeedRatio`、单技能动作速度以及 Actor2 状态切换，不要先调整 NPC 视野系统。
