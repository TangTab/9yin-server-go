# 宝物随机词条与野怪全道具掉落说明（2026-09-08）

## 需求

1. 所有 `treasure_` 宝物（宝箱开出 / GM 刷出 / 任何途径进包）默认自带
   **恒定 7 条属性词条 + 随机同一个套路 3~5 个招式伤害加成**，数值随机。
   其中**气血上限、招架耐力上限为固定词条**（词条族必出、数值在区段内
   随机），其余 5 条从属性池随机（对齐官服「翡翠墨玉璜」截图定稿，
   2026-09-08 19:08）。
2. 属性池覆盖官方宝物词条：气血/内力上限、气血/内力恢复速率、招架耐力
   上限、轻功值上限、近身/内功/远程威力、外功/内功暴击率、外功/内功暴击
   伤害、外功/内功命中率、忽视外功/内功防御、忽视刚/柔/阴/阳防御、外功
   招架忽视、忽视内功化解、受到暴击伤害降低(爆免)、被暴击几率降低、闪避
   率、外功/内功防御、刚/柔/阴/阳防御。
3. 打死野怪弹出的拾取框额外随机给 **3~5 件全道具池物品**（equipment.ini
   + tool_item.ini 全表抽取，可开出带词条的装备/宝物）。

## 实现

### 1. 词条数据源（全表扫描实证）

每条词条 = 一个 proppack.ini 段 id（`PropModifyPackRec`，PackRec=PropBuilt=id）。
客户端 tooltip 按 `tips_proppack_<id>` 渲染中文，服务端战斗按
`installedPropPacks`（proppack.ini）计算加成，同源同值。
用脚本扫全表后，每个词条族选用「ID 连续、数值等差、tips 与 proppack
数值一致」的干净区段（见 `treasure_affix.go` 的 `treasureStatPacks` 表，
每条区间都经脚本核验）。

### 2. 注入点（一次掷定、全链路一致）

- `treasure_affix.go`（新增）：
  - `isTreasureItem`：ConfigID 前缀 `treasure_` / EquipType=Treasure /
    ItemType=146 任一命中。
  - `rollTreasureAffixes`：**固定词条 气血上限 + 招架耐力上限 2 条 + 其余
    属性族随机 5 条（恒 7 条、互不重复，数值在族区段内随机取 id）** +
    `rollTreasureSkillPacks`（随机一个套路 → 同套路 3~5 个互不重复的
    PackCategory=5 skillpack，复用 weapon_recast 的 skillpack 表，
    245 个套路可用）。
- `equip_gear.go attachDefaultAffixes`：宝物在默认装备词条链之前短路进
  `attachTreasureAffixes`。该函数是所有权威物品入包的统一漏斗
  （`addItemToLoot`：GM 刷物 seedGMItems、拾取 380、奖励），因此**任何
  途径进包的宝物都会掷词条且只掷一次**（已有词条不重掷）。
- `chest_loot.go`：
  - `rollChestLoot` 增加随机宝物 x1（treasure_ 全表抽取）。
  - `openChestLootDrop` 在拾取窗种子上 `fillItemMeta + attachDefaultAffixes`
    —— **拾取窗预览的词条 = 最终到手词条**。
- `drop_loot.go`：
  - `handlePickupDropCustom`：非堆叠物（装备/宝物）拾取时把种子上掷好的
    Affixes/SkillPackRecs 原样带入背包（limit==1 保证单槽位，不污染堆叠）。
  - `openKillDrop`：野怪击杀掉落框在原掉落表之后追加
    `rollRandomAnyItems(3~5)`（`allItemConfigPool`：equipment.ini +
    tool_item.ini 全表去重池，进程内构建一次；堆叠物 1~3 个、装备/宝物
    1 件；种子上同样预掷词条），槽位上限 16 不变。

### 3. 持久化

词条随 `inventory.Item`（json affixes / skill_pack_recs 字段）走
`persistLootGear` → equip.json，重登不丢。

## 官方显示通道迁移：RandomPropRec / RandomSkillRec（2026-09-08 20:15 定稿）

用户提供了官服 tooltip 的真实渲染公式（tips.idres 原文），确认宝物词条的
官方显示路径是**原生记录行**，不是此前接的 PropModifyPackRec /
SkillModifyPackRec 通道：

```
tips_maxhpadd        = 气血上限+{@0:value}          ← GetPropText(id, value)
tips_vadamagedefadd  = 暴击伤害减免+{@0:value}%      ← GetPropText
tips_revise_skill_prop = <套路的招式>                ← GetSkillText(id, skill_id, value)
tips_xxdamageadd     = 每击伤害+{@0:value}           ← GetSkillText
```

### 实现要点

- **记录下标**：H 的 0x0A schema 表比 D:/ 多出兵录/时装/梳妆阁等追加段，
  `RandomPropRec=30`、`RandomSkillRec=31`（D 是 23/24）。0x0A 按整表
  协商、客户端按协商位置按名注册，位置无需与 D 一致；item_records.go 的
  `init()` 对 4 个记录下标做名字断言，表漂移立即 panic 暴露。
- **下发**：`treasureRecordRows`（item_records.go）按 target=1、
  objectID=viewID、ownerID=槽位 发射 RandomPropRec 6 列
  （id, double value, lock, flag, revise_level, revise_power）与
  RandomSkillRec 4 列（skillstore 节号, 招式数字 static id, double value,
  套路类型），倒序发射（SERVER_RECORD_ADD 插行 0）。已折叠进
  `itemRecordFrames`，7 个调用点（装备视图 1、背包 2/174、掉落框 80、
  克隆奖励 127、attire 584 等）全部自动携带。
- **双通道互斥**：宝物带 TreasureProps 时不再发
  PropModifyPackRec/SkillModifyPackRec 行，否则 show_ModifyPack_info 会把
  同一批词条按 tips_proppack_<id> 再渲染一遍（招式行还会显示成
  「威力增加N成」）。普通装备仍走 ModifyPack 通道（有回归测试保护）。
- **显示/战斗同源**：`rollTreasureSkills` 返回 (rows, packs)，rows 是
  skillstore 行（显示），packs 是与之逐条同招式匹配的 PackCategory=5
  skillpack（战斗威力乘区）；`it.SkillPackRecs = packs`，
  服务端战斗计算不变。
- **节号 ≠ 切片下标 bug**：skillstore.ini 按 map 迭代序解析，节号 [N] 与
  切片位置不一致；RandomSkillRec.ID 发的是节号，新增
  `treasureSkillstoreByIndex`（节号 → 行）回查，测试曾抓到串套路问题。
- **旧存档修复**：`ensureTreasureDisplayRecords` 挂在 `fillItemMeta`，
  TreasureProps 为空的宝物在首次视图同步前补掷一套并随存档持久化
  （只触发一次，不会每次同步重掷）。

### v6 上线：宝物属性加成真实生效到玩家（2026-09-08 22:2x 用户定稿）

**规则**：只有**穿戴中**的宝物生效；生效值 = tooltip「属性加成」里实际
显示的行（TreasureProps 显示轨，看到什么加什么）；卸下宝物重算即清零。
宝物的战斗轨（Affixes proppack）不再参与属性折算（其数值与 tooltip 不
一致）。

**实现**：
- treasure_stats.go：`treasureStatBonus`（按 propstore 节号映射）+
  `aggregateTreasureBonus`（只扫 loot.equip 穿戴位）。
- syncEquipCombat：宝物跳过 affix 战斗轨；显示轨合计进
  `loot.treasureBonus`；气血/内力上限并入 loot.equipMaxHPAdd/MPAdd 既有
  通道（actor 真实上限 + MaxHPAdd/MaxMPAdd prop 自动带上）。
- recomputeCombat：威力(近身/内功/远程)、命中(外/内)、闪避、外功防御、
  四防(刚柔阴阳)、招架耐力上限(maxParryAdd)、内功防御(minMagicDefAdd)、
  暴击率(phyVa/magicVaProbAdd)、气血/内力恢复 并入 tb。
- properties()：MaxParryAdd/MinMagicDefAdd prop 改为「内功黄字 + 经脉 +
  宝物」合计（此前只出内功黄字）。
- finishEquipChange：装备变化后立刻 recomputeCombat（穿上加/卸下清的
  即时性）。
- **不生效的词条族**（面板/属性无对应字段，用户定稿「没出现的不加」）：
  暴击伤害提高/降低、被暴击几率降低、忽视系(AIPhy/AIMagic/刚柔阴阳防御
  忽视/外功招架忽视)、轻功值上限。后续战斗公式扩展后在 addProp 补映射。
- 测试：treasure_stats_test.go（穿戴生效/卸下清零/背包不生效）。
