# 身份装/时装外观显示修复说明（2026-09-11）

## 需求

人物属性面板（江湖装/身份装/时装）中的**身份装栏位**：把身份装道具装进栏位后，
角色显示该身份装的整套模型。外观优先级（逐部位）：

```
风物志卡牌(已装备) > 时装分件(栏位17/18/19) > 身份装整套(栏位16 或列表穿戴) > 梳妆阁图纸融合 > 真实装备
```

即：没装备风物志卡牌时，优先显示穿戴中的身份装整套模型；时装分件盖住对应部位；
什么都没穿时显示真实装备。

## 客户端协议事实（逆向解包结论）

- 面板身份装/时装栏位就是**装备视图（VIEWPORT_EQUIP）槽位**：
  `form_new_rp_arm.lua init_bind_view_index`：suit_grid 绑定 16(身份装)/17(时装外套)/
  18(时装帽)/19(时装鞋)；新面板 new_equip_grid 对应 40-43。
- 身份装道具 = equipment.ini 中 `EquipType=Suit`、`ItemType=180`（一整套）的条目
  （如 shaolin01、cloth_origin_2701、sh_gs_01），模型 = ArtPack → itemartstatic.ini
  MaleModel/FemaleModel；可选部件 HatArtPack / PlantsArtPack(裤子) / ShoesArtPack。
- 「已激活」角标：native `IsFashionSuitActived` 读玩家记录 **FashionSuitRec** col0。
- 列表点「穿戴」：`CustomSend(19, 1, configID)`；suit_grid 右键卸下：
  `CustomSend(19, 2, 槽位属性名)`（Suit/NewSuit=整套，官方由服务端把道具移回背包）；
  购买：`CustomSend(19, 3, configID)`。
  （注意：sub=2 此前被误当「激活」，实为右键卸下。）

## 补充：栏位道具 tooltip 图标/描述不显示（2026-09-11 晚）

现象：身份装道具装入栏位后，悬停 tooltip 名称为红字、图标/模型框空白、底部显示
原始键（如 `desc_银宵沧海_0`）。

根因（客户端侧，与服务端无关）：
- 身份装栏位的 tooltip 走 `show_fashion_suit_tips`（静态 config tips），而
  suit_grid 的 `GetItemName` 返回的是**本地化名称**（如 银宵沧海），不是 config id
  （b_lingxiao_ch_04）。原生 tips 拿名称串查 icon/model/desc 全部落空：
  名称红字=未识别、图标/模型空、desc 键拼成 `desc_银宵沧海_0`。
- 描述文本实际存在但键不同：`desc_b_lingxiao_ch_04=海宫蹙浪…`（desc2.idres，
  无 `_0` 后缀）。

处置（客户端文本数据补丁，非 Lua）：
- `_patch_suit_desc.py`：为全部 1073 套身份装/时装套装生成
  `desc_<名称>_0=` 与 `desc_<config>_0=` 两种键的条目（去重），追加到
  正式客户端 `D:\游戏蜗牛\9yinjh\text\text\chineses\desc2.idres`；
  原文件备份为 `desc2.idres.bak-20260911`（还原即拷回）。
- 已有描述的 573 套补后 tooltip 能显示描述文本；无描述数据的 500 套显示空白
  （不再是原始键）。
- 图标/模型框若补丁后仍空，属于客户端 icon.package 资源缺口
  （itemartstatic 指向 icon\equip\b_s_lingjiu_1.png），文本表无法修复。
- **需重启客户端生效**（文本表启动时加载）。

## 栏位道具化 + 发型同步（2026-09-11 17:40 更新）

### 新版面板「穿戴」= 真实道具进栏位
- 点穿戴（C2S 19 sub=1）服务端现在从装备背包/背包找到该服装道具实例，经标准装备路径装进**槽 16**，并自动镜像到新面板**槽 40**（同一道具实例挂两槽，16-19↔40-43 成对同步，任何装备变动后由 finishEquipChange/publishGearViewsPlayer 自动对齐）。新老两个人物属性面板的栏位都会显示道具图标。
- 找不到道具实例（未持有）时退回原「列表穿戴」状态（wornSuit），模型照常显示。
- 右键栏位（sub=2，Suit/NewSuit/分件 New* 均支持）或把图标拖出栏位：成对槽位一并清空，道具只回装备背包一次；背包满则回滚取消。模型恢复真实装备外观。

### 发型跟随身份装
- 场景头部/发型皮肤由 **Hair 属性（index 13）** 驱动，Hat（35）是叠加层。身份装条目声明 HatArtPack（头部部件，如银宵沧海 55014）时，套装头模经 Hat 皮肤显示，同时服务端下发 Hair="" 清空基础发型 —— 发型即同步为身份装的发型；卸下后恢复创建角色发型（player.baseHair）。
- 风物志卡牌接管 Hat 槽时不动发型；选择人物界面预览由 rolePara 的 hat 字段自动屏蔽基础发型，无需额外处理。

### 发型显示优先级（2026-09-11 19:30 定稿）
Hair 属性（index 13）的清空/恢复跟随 **Hat 槽的赢家**，与整体外观优先级一致：

1. **风物志卡牌发型**（纯发型卡 / 卡牌 Hat 部件）→ 清空基础发型
2. **时装分件帽子**（栏位 18/42，走 identitySuitSlotOverrides 分件覆盖）→ 清空基础发型
3. **身份装整套头模**（HatArtPack，如银宵沧海 55014）→ 清空基础发型
4. **梳妆阁图纸融合**（图纸绑定帽子部件）→ 清空基础发型
5. **真实装备帽子**（封闭头盔）→ 不清基础发型（维持原状，头盔遮盖）
6. 以上都不接管 Hat 槽 → 显示创建角色发型（player.baseHair）

同一来源接管即由其头模经 Hat 皮肤显示 = 该来源的「发型」；高优先级来源卸下后自动回落到下一级。选择人物预览由 rolePara hat 字段自动屏蔽发型，规则一致。

### 头模通道修正（2026-09-11 19:50，实测银宵沧海后定稿）
- 实测发现：套装头模只推 Hat(35) 时**头发不变** —— 客户端场景/预览的头部皮肤模型实际由 **Hair 属性(index 13) 驱动**（实证：form_attire_main.lua:713 / form_onestep_equip.lua:937 / form_card.lua:1145 均用 QueryProp(\"Hair\") 作 hat_model 组装头模；form_main_player.lua:229 绑定 Hair 属性变化→on_refresh_role_face 刷新脸模）。Hat(35) 只是帽子叠加层。
- 修正后 pushGearVisual：头模赢家（风物志卡 > 时装分件 > 身份装 HatArtPack > 图纸融合）直接下发 **Hair=赢家头模、Hat=\"\"**（防旧帽叠加）；无赢家时 Hair=baseHair、Hat=真实装备帽。真实装备帽子仍走 Hat 叠加层（封闭头盔，不动发型）。
- 服务端链路回归测试 identity_suit_hat_debug_test.go：槽 16 挂 b_lingxiao_ch_04 → slotOverrides 必含 Hat 键（防目录/解析回归）。
