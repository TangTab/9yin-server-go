# 九阴建角初始数据归纳（RoleBaseProp.xml）

> 数据来源：`testdata/lua/`（九阴官方脚本）+ `testdata/ini/CreateRole/RoleBaseProp.xml`。
> 本文是建角初始数据的唯一归纳入口：格式分析、属性体系、派生公式、门派/出生地规则、字段映射与复算表。

---

## 1. RoleBaseProp.xml 原始格式分析

### 1.1 物理格式

| 项目 | 说明 |
|---|---|
| 编码 | UTF-8，无 DTD/命名空间 |
| 根节点 | `<Object>` |
| 数据行 | `<Property .../>` 自闭合标签，一行一个建角组合 |
| 数据形态 | 纯属性键值对（XML attribute），值均为字符串形式的基本类型 |
| 空槽占位 | 全 0 / 空串（`HP="0" ... TransConditionId=""`） |

### 1.2 原模板 ID 编码与字段语义

原模板（阵营/种族/职业制）注释：`ID对应 阵营10 + 种族10 + 职业1`，即：

```
ID = 阵营×10000 + 种族×100 + 职业
```

| 原字段 | 语义 |
|---|---|
| `HP` / `MP` / `Physical` | 初始生命 / 法力 / 体质 |
| `GuardSkill` | 初始守护技能 ID |
| `AttributeID` | 关联属性组（外观/属性表）ID |
| `TransJobList` | 可转职列表（逗号分隔） |
| `DoTransJob` / `CantTransJob` | 转职开关 / 禁转矩阵（`;` 分组、`,` 分隔） |
| `TransConditionId` | 各转职条件 ID（`;` 分隔） |
| `AutoQuestFlag` | 建角自动任务标记 |

Go 侧消费点：`internal/fsgame/rolemods.go` 的 `CreateRoleModule`（`IsCanCreate(camp, race, job)` / `onCreateRole` 属性初始化链），表接线待静态数据里程碑。

## 2. 九阴建角维度与新 ID 编码

九阴建角没有阵营/种族/职业，实际维度是 **出生地 × 性别**，新角色一律 **无门派**（`School=""`）。

```
ID = 出生地×10 + 性别
出生地: 1=烟雨庄(born03)  2=千灯镇(born04)  3=苏州(city02)
性别:   1=男  2=女
```

| ID | 出生地 | 场景资源 | 性别 |
|---|---|---|---|
| 11 / 12 | 烟雨庄 | `born03` | 男 / 女 |
| 21 / 22 | 千灯镇 | `born04` | 男 / 女 |
| 31 / 32 | 苏州 | `city02` | 男 / 女 |

出生地只影响出生场景与初始任务链，**不影响属性**；性别亦无属性差异（原模板的差异来自种族职业制，九阴无此机制）。

## 3. 属性体系（官服口径为权威，内测 lua 方言见附录 A）

### 3.1 五维与主要提供（官服）

| 五维 | 属性名 | 主要提供 |
|---|---|---|
| 臂力 | `Str` | 近身威力、外功暴击、少量气血 |
| 身法 | `Dex` | 远程威力、外功命中、闪避 |
| 内息 | `Ing` | 内功威力、内力 |
| 罡气 | `Spi` | 内功命中、内功暴击、少量内功防御 |
| 体魄 | `Sta` | 气血、封劲、招架值 |

> `Esth`（感知）为 2009 内测 lua 的隐藏属性（参与暴击/精准/闪避等级低权重分量），官服建角体系无此维；引擎 schema `rule/baseprop/baseprop.xml` 仍保留该位。

### 3.2 衍生属性（官服口径，抓包证实）

| 属性 | 主要来源 | 作用 |
|---|---|---|
| 气血（HP） | 内功（大量）、体魄、臂力 | 生命值 |
| 内力（MP） | 内功（大量）、内息 | 使用大部分招式都要消耗内力 |
| 近身威力 | 臂力 | 为带红色数字的招式提供额外伤害加成 |
| 内功威力 | 内息 | 同上，对应蓝色数字 |
| 远程威力 | 身法 | 同上，对应绿色数字 |
| 外功暴击 | 臂力 | 根据对手封劲经复杂计算后，决定外功招式的基础暴击率（上限 15%，下限 0） |
| 外功命中 | 身法 | 根据对手闪避，决定外功招式命中率 |
| 内功暴击 | 罡气 | 效果与外功暴击基本一致 |
| 内功命中 | 罡气 | 根据对手闪避，决定内功招式命中率 |
| 封劲 | 体魄 | 降低自己被暴击的概率（内外功通用） |
| 躲闪 | 身法 | 降低自己被命中的概率（内外功通用，wire `dodgeadd`=躲闪值） |
| 外功防御 | 装备为主 | 降低所受外功伤害 |
| 内功防御 | 装备、经脉、内功 | 细分阴/柔/阳/刚防御，降低所受对应属性伤害 |
| 怒气（SP） | 运行内功档位加成上限 | 招式资源；上限 = 基础 80 + 内功档位（10~50） |
| 轻功值 | — | 轻功消耗资源（初值待考） |
| 格挡（招架 Parry） | 体魄等 | 招架耐力；上限 = 白板 100 + 各来源 Add |

**五维逐点收益**（官方 55866/12173 抓包逐点解出，b-line `player_progress.go` 实现同源）：

| 五维 | 每 1 点收益 |
|---|---|
| 臂力 | +1 近身威力、+2 生命上限、+1 外功暴击值 |
| 身法 | +1 外功命中、+1 闪避值、+1 远程威力 |
| 内息 | +1 内功威力、+4 内力上限（旧版攻略"×3"为旧口径；抓包与客户端 form_rp_arm tooltip 均为 ×4） |
| 罡气 | +1 内功命中、+1 内功暴击值、+1 内力上限、每 5 秒回复 0.2 内力、+0.2 内功防御 |
| 体魄 | +7 生命上限、+0.5 防御力、每 5 秒回复 0.07 生命 |

## 4. 升级加点规则（`player/baseprop.lua`）

- **1~10 级**：每升 1 级五维各 +1（`alloc_baseprop_point`）。
- **10 级后**：每升 1 级共 3 点，按门派分配；**无门派（`School` 为空或未知名）时 Str+3**。
- 首次上线触发 `BORN` 特效（`player/Player.lua` → `SERVER_CUSTOMMSG_EFFECT`）。

## 7. 后续使用指引

1. **建角流程**：`CreateRoleModule.onCreateRole` → 读表按 `ID`（出生地×10+性别）取行 → `SetInt` 写入 `Str/Dex/Ing/Spi/Sta/Esth` 与派生 `HP/MP/EY`、`Scene/Sex` → 场景 ready 后按 `InitTask` 走 `FreshmanHelp` 引导。
2. **公式实现**：Go 侧实现 §3.2 派生公式作为 `PropRefreshFunc` 对应物，属性名保持与 lua 一致（大小写敏感），record 0/1 语义对应「次级属性影响 / 装备buff直供」。
3. **升级实现**：`alloc_baseprop_point` 的 Go 对应物按 §4 表驱动，`School` 属性缺失时走 Str+3 分支。
4. **数据校验**：改表后用 §6.2 官服公式复算 HP/MP/SP/Parry 是否自洽；XML 良构性用 `python -c "import xml.etree.ElementTree as ET; ET.parse(...)"` 快速验证。

## 附录 A：内测方言派生公式（2009 lua，仅供引擎史参考）

> 以下为 `player/PropRefreshFunc.lua` 的内测公式，与官服抓包口径（§3.2）**不可混用**——系数体系完全不同（如 MaxHP=Str×4.5+Sta×12.8 vs 官服 2·Str+7·Sta 的 Add 分量制）。

| 派生属性 | 内测公式 |
|---|---|
| MaxHP | `Str×4.5 + Sta×12.8` |
| MaxMP | `Ing×22.5` |
| MaxEY | `Str×15` |
| 外功攻击强度 IntPhyAttack | `Str×1.2 + Sta×0.3` |
| 内功攻击强度 IntMagAttack | `Ing×1.2 + Spi×0.3` |
| 最大/最小物理攻击 | `IntensityPhyAttack×1.2 / ×0.8` |
| 最大/最小法术攻击 | `IntensityMagicAttack×1.2 / ×0.8` |
| 暴击等级 CritLevel | `Dex×0.2 + Esth×0.03125` |
| 法术暴击等级 MagCritLevel | `Dex×0.03125 + Esth×0.2` |
| 精准等级 AccurateLevel | `Dex×0.25 + Esth×0.03125` |
| 法术精准等级 MagPrecLevel | `Dex×0.03125 + Esth×0.25` |
| 闪避等级 DodgeLevel | `Dex×0.25 + Esth×0.03125` |
| 法术闪避等级 MagdodgeLevel | `Dex×0.03125 + Esth×0.25` |
| 全法术抵抗 AllResist | `Ing×0.01 + Spi×10.5` |
| HP/MP/EY 回复速度 | `Str×0.02+Sta×0.09+4` / `Spi×0.25+4` / `Spi×0.05+4` |

## 8. 任务目录生成工具（cmd/taskgen，源自 official-2433-b-line 分支）

初始任务脚本在 testdata/lua/task/ 中缺失（见 §5），完整任务目录由客户端资源派生。相关代码已从 `official-2433-b-line` 分支搬运至本分支：

| 组件 | 位置 | 说明 |
|---|---|---|
| 传输层 | `internal/transport/` | connection/frame/key（连接、帧、密钥），纯标准库，含测试与抓包夹具 `testdata/protocol/connect-first-flight.bin` |
| 任务数据包 | `internal/taskdata/` | Task/Binding/DramaCite/Catalog 模型 + idres 文本/storytasklist 绑定/qianjiu NPC 表/戏剧引用解析 + JSON 快照 |
| 生成工具 | `cmd/taskgen/` | 独立 CLI，逻辑复刻 b-line `cmd/protocol-probe/task_catalog.go` 的派生链，资源访问退化为直接文件系统读取 |

**数据源**（工程根 `resources/` 下）：
- 任务文本 `text/chineses/stringtask_normal/*.idres`（TID 前缀白名单见 `internal/taskdata/text.go`）
- NPC 绑定 `share/task/task/storytasklist/*.txt` + `share/task/qianjiu_tasknpc.ini` 的 `[TaskNpc]` 段
- 任务链 `share/task/task/task_drama_cite.ini`

**用法**：

```bash
go run ./cmd/taskgen [-root <工程根>] [-out <tasks.json>] [-force]
# 工程根定位：-root > NINEYIN_SERVER_ROOT 环境变量 > 向上查找含 resources/modern/share 的目录 > 工作目录
# 默认输出 <root>/artifacts/local/tasks.json；已有有效快照时直接复用，-force 强制重扫
```

派生语义与 b-line 一致：文本与绑定目录缺失属致命错误；单文件解析失败记日志跳过；快照原子落盘（临时文件 + Sync + Rename）。
