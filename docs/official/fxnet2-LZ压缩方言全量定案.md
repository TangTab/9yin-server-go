# fxnet2 LZ 压缩/解压官方方言全量定案

> 权威来源：`tmp_carve/fxnet2_rebuilt.dll`（文件偏移==RVA、
> ImageBase=0x10600000）。**取代** `op28-fxnet2-lz-decoder.md`（2026-11-11 磁盘版反汇编，
> RVA 漂移+语义近似， lzdec.py 三处偏差之源）。工程实现：`tools/lz_exact.py`。

## 一、函数与槽位地图（RVA 相对 0x10600000）

| RVA | 角色 | 说明 |
|---|---|---|
| **0x1420** | 解压核心 | rcx=帧(含mode), rdx=dst, r8=outlen, r9=池ctx |
| **0x1730** | 帧解包 | mode&2→头3/9字节；mode&1→解压否则 memcpy；每帧后 `ctx+0x9000=0` |
| **0x10e0** | 压缩核心 | 单探针贪心；调用方 0x1620 |
| **0x1620** | 压缩包装 | outlen<0xd8→3字节头否则9；**池 pos 字段每调用全清零**；len≤0xfffffe6f |
| **0x1d0bd** | 唯一解压调用点 | op29 分发：dst=`[rbx+0x88]+1`（会话缓冲），池=**全局静态** |

**池（相关槽）结构**，`0x106552F0`（.data+0x32F0），大小 **0x9008**：
- `[0x0000, 0x8000)`：**4096 个 qword 指针槽**（指向会话缓冲内绝对地址）
- `[0x8000, 0x9000)`：4096 字节 **valid 位图**（注册置 1；match 取指针**从不查位图**）
- `+0x9000`：qword 每帧清零字段（错误/游标类，非池本体）

生命周期：**进程级单例、代码中仅 0x1d0ae 一处引用、无任何重置**。
解码侧跨帧持久 + 指针指向**每连接复用的会话缓冲**（前缀被逐帧覆写）。
压缩侧（客户端 C2S 0x1620）每帧清池 ⇒ 自包含；**外服 S2C 编码器则跨帧复用池**（实证见 §四）。

## 二、帧头方言

| mode | 含义 |
|---|---|
| 0x44 | raw + 3字节头 |
| 0x45 | LZ + 3字节头 |
| 0x46 | raw + 9字节头 |
| 0x47 | LZ + 9字节头 |

- 3字节头：`[mode][帧总长 u8][outlen u8]`（outlen≤255）
- 9字节头：`[mode][帧总长 u32][outlen u32]`
- 头长选择：outlen < 0xd8 → 3字节
- outlen 提取（0x1730）：`u32@frame[1+r9] & (0xFFFFFFFF >> ((4-r9)*8))`，r9 = (mode&2)?4:1
  —— 3字节头掩码 **0xFF**（旧工具读 u32 不掩码是 bug）
- 压缩 bailout：输出 > 消费×31/32 且已过半程 → 整帧 raw（0x44/0x46）

## 三、位流语义（编码/解码镜像）

flags u32，LSB 先消费，`flags==1` 触发重填（哨兵位=已用位数上的单个 1）。
**编码器倒序构造**（reg 位 31 哨兵下移，match 位 bts 顶入；满词/收尾 `shr+bts31` 归一化）
——满词=31 token 位+哨兵@31，部分词=token 位+零隙+哨兵@31，两者对解码器等价。

- **bit0=1 match**：peek u32；`idx=(v>>4)&0xfff`；`nib=v&0xf`
  - nib≠0 → len=nib+2 (3..17)，消费 2 字节；nib=0 → len=byte[+2] (≤255)，消费 3 字节
  - 拷贝：**步长3宽4 的前向重叠块复制**，块数=ceil(len/3)，读活缓冲区（距离<len 时
    自引用=RLE 复制），末块溢出 ≤3 字节（留在缓冲区、可被后续边界 hash 读到）
- **bit0=0 literal**：n=flags&0xf，k=T[n]，T=`[4,0,1,0,2,0,1,0,3,0,1,0,2,0,1,0]`
  - **先写 peek 的 u32 共 4 字节到 dst[write]**（k<4 时后 k' 字节=流内后续字节溢出，
    确定性留在缓冲区），再 write+=k、src+=k、flags>>=k
  - 连续字面量位流自动分组：n=0（0000）→4字节；n=8（1000）→3字节+终止位；
    n=4（0100）→2字节；n=2（0010）→1字节——终止位 1 与后续 match 位共享
- **注册**（hash=`((u32@pos>>12)^u32@pos)&0xfff`，单槽覆盖）：
  - literal 后：pos=window+1 … write_new-3 **含端点**（边界 hash 含 peek 溢出字节）
  - match 后：pos=window+1 … write_old **含端点**（hash=match 首四字节）；随后
    window=write_new-1（**match 内部位置永不注册**——编码器镜像同规则）
  - 尾段内逐字节注册到 end-3；尾后终注册到 outlen-4 含端点
- **编码端查匹**：单探针（注册后取旧槽值），key=u32 值本身，**低 24 位相等**=前 3 字节相等；
  全 32 位相等才扩展；距离 ≤2 仅允许距离 1 且 RLE（body[cur-3..cur+3] 共 7 字节全等）
  且前导字面游程 ≥3；扩展上限 `min(end-cur-2, 0xff)`；len<0x12→2字节 token（nib=len-2）
  否则 3 字节（len 全值在 byte2；**第 4 字节是会被覆写的溢出，不占流**）
- **尾段**：`write ≥ outlen-0xb` 且**下一 token 是字面量**才切换（0x152f 闸门在字面量分支
  ——尾段区 match 照常解码！）；逐字节每字节 1 bit（位值无关）；重填=**跳过 u32 不读**、
  flags=0x80000000（官方 filler 恒定，与读入等价）；字节面与主循环数据连续，切分点不对齐也自洽

## 四、官方真帧验证（7 包 pcapng，F:\...\artifacts）

| 解码器 | ok / fail | 通过率 |
|---|---|---|
| 旧 lzdec.py（磁盘版近似+跨帧堆拼接） | 2851 / 665 | 81.1% |
| lz_exact 帧模式（每帧独立池） | 3284 / 232 | 93.4% |
| **lz_exact 会话模式**（持久池+缓冲覆写） | **3386 / 130** | **96.3%** |

- **跨帧池引用实锤**：op 0x2D 帧首 token 即 match（`pool miss at out[0]`），会话模式全解
- **旧解码器静默产错数据实锤**：双解成功帧输出大面积不同（op39 outlen=3527 差 1277 字节）
  ——根因=重叠复制用预写切片 + 边界注册漏 write-3 槽
- 进程级全局池（跨连接共享）与每连接会话池**打平**（3386/133）——跨连接无增益
- 剩余 fail 归因抓包缺帧（引用槽在捕获内从未注册）/流失步重同步伪帧

## 五、坑（旧结论勘误）

1. 磁盘版 RVA 与运行时漂移：lzdec.py 头注「RVA 0x1000-0x1260」实为磁盘文件偏移，且
   重建版同址是别的函数——反汇编必须用 DMP 抠取版
2. 反汇编切片勿从指令中间起：0x126f `41 d1 eb`（shr r11d,1）被切掉 REX 后误读
   `shr ebx,1`，差点定错标志位寄存器
3. 3 字节 token 的 dword 写入第 4 字节是溢出覆写语义，bytearray 追加模型必须裁掉
4. 尾段闸门位置：在字面量分支而非循环头——循环头版会把尾段区 match 拦死（600 例压测可抓）
5. 旧 lzdec 尾段「读 u32 当 flags」与本码「跳过+0x80000000」字节面等价（filler 恒定），
   但头部长度/outlen 掩码与注册/复制语义三处真错
