## 一、总评：战斗模式

九阴的战斗机制很有新意：有一定的操作门槛，但没有纯动作游戏那么高的上手难度，因为存在大量的锁定技能。

但对以下三项要求很高：反应速度、技能熟悉程度，以及硬性条件——网速。

## 二、武学、招式与冷却

- 技能又称**招式**，招式组成一套套**武学**。武学可理解为一套招式组，其中包含多个招式。
- 一套武学内的招式，可在**各自冷却**的基础上自由使用；但非本武学的其他武学招式，要等待 **7 秒的公众冷却**（原文用词，通行写作「公共冷却」）。

> 原文举例：有两套武学 A 和 B。A 有 7 个招式 A1～A7，B 可能有 8 个招式 B1～B8。招式本身各有冷却（一两秒到几十秒不等）。只要使用了 A1～A7 中任意一个招式，那么除 A1～A7 之外的所有其他招式（B1、C3 等）都要等待一个 7 秒的公众冷却。

## 三、招式五大类

| 类别 | 定位 | 克制 / 交互关系 |
|---|---|---|
| **实招** | 大部分简单直白的攻击性招式 | 克制虚招；被架招克制；命中格挡目标时伤害大降、大部分控制失效 |
| **虚招** | 破防用招式 | 直接击破右键格挡，并按描述附加效果 |
| **架招** | 格挡成功后触发增益 / 负面的永久状态 | — |
| **气招** | buff 类招式 | — |
| **怒招** | 需足够怒气释放，多为套路终极技能 | — |

**实招**：大部分简单直白的攻击性招式均为实招。实招克制虚招，但被架招克制。与对手同时出招，若己方实招对上对方虚招，会出现「克制」字样，且实招自带的任何控制效果都将打断对手动作（原文作"都将将"）。而若实招命中的对手处于格挡状态，伤害将极大降低，且其对应的大部分控制效果无法生效。

**虚招**：破防用招式。对处于右键格挡状态的目标，直接击破其格挡状态，并根据招式描述造成额外效果（击飞 / 击倒 / 眩晕等）。

**架招**：战斗中玩家按住右键，角色进入格挡状态——按自身**外功招架 / 内功化解**属性大量降低所受外功 / 内功伤害，同时免疫绝大部分控制技能。架招则是给你增加一个**持续时间永久**的状态：格挡成功后获得不同增益效果，或给对方添加不同负面效果。

**气招**：buff 类招式。

**怒招**：需要足够怒气才能释放，大多为一个套路中的终极技能。

## 四、战斗主轴：格挡、破防与反制

九阴的战斗过程总的可模糊概括为：

> 双方按住右键格挡，然后凭借反应，进行虚招破防，或者实招反制的过程。

反应速度、对上百种招式出手动作的熟悉程度，决定了最终操作水平。还有网速。

## 五、冲锋招与网速

网速优势在九阴战斗机制中能占得最大先机，原因是一种特殊的【实招】——**冲锋招式**。

**识别方式**：技能说明里有「（此招式可利用轻功快速接近对手）」。

**锁定机制**：释放该招式后，若目标在招式射程范围内，你和对手会**同时进入锁定状态**——你只能出招打人，对手只能不动挨打。哪怕对手正在格挡，你也可以怼着他的格挡把冲锋招式完整放完，期间双方都不能行动（部分情况可例外，比如霸体或解控招式）。

**毫秒级锁定时间差**：锁定时间虽然大致一样，但对自身的锁定时间略微短一些（毫秒级别）。这意味着：若你网络延迟比对方低、并对对手连续使用冲锋招式，对方连逃跑 / 反击 / 格挡都做不到。一点点的网速优势都会极大受益。

**附加控制效果**：许多套路的冲锋技能自带控制或特殊 Buff（击倒、击飞、定身或附加特定套路状态），冲锋命中后可以顺畅接上大招或其他实招，是打出一套完整爆发连招的起手核心。（该段原文重复出现两次，整理保留一处。）

俗话说得好：九阴战斗胜负，属性 + 操作占 40%，网速占 60%，毫不夸张。

## 六、轻功

和大多武侠网游一样，九阴也有轻功，但**大多在战斗中使用**，且需技能书学会后方可使用。常用的有：

| 轻功 | 操作 | 效果 |
|---|---|---|
| 扶摇步法 | — | 三段跳 |
| 穿云纵 | 起跳＋方向键连按两下，第二下长按 | 人物在空中穿行一段距离 |
| 雁行功 | 方向键＋轻功快捷键 | 人物在地面滑行一段距离 |
| 上天梯 | 靠近墙面，方向键＋轻功快捷键 | 人物会爬墙 |
| 踏波行 | 在水面，方向键＋轻功快捷键 | 人物在水面快速移动 |

等等……（原文列表非穷举）

- 轻功消耗**轻功值**：满值 150，少量特殊道具可增加上限。
- **消耗得越多，恢复速度越慢**。
- 战斗中善用轻功，可进行迂回 / 躲避 / 追击。

## 七、控制类型

比较简单直白的：**击飞、击倒、击退、眩晕、僵直、减速、定身**。

叫法特殊的：

| 控制名 | 效果 |
|---|---|
| 禁轻功 | 无法使用轻功 |
| 封招 | 无法使用招式 |
| 点穴 | 类似眩晕 |
| 冰冻 | 类似眩晕 |
| 魅惑 | 类似眩晕 |
| 不可招架 | 无法进行格挡 |
| 无视格挡＋上述控制效果 | 无视对方的格挡状态造成控制效果（很罕见，也很强） |

## 八、霸体

**（本节前半为战斗篇原文；「扩充」部分并入自原《九阴战斗机制 · 霸体》汇编稿，2026-11-07 整理，口径一致。）**

九阴的霸体分为三种：**白霸体、黄霸体、红霸体**。

白霸体和黄霸体其实不用多做细分——只要知道**眩晕和类似眩晕的控制可以打断这俩霸体**就行。红霸体**不受任何控制**。

霸体招式在对决过程中优势很大；附带霸体且有控制效果的招式，能帮助你获得极大的优势。

**扩充 · 总览表**

| 类型 | 特性 | 克制关系 |
|---|---|---|
| 白霸体 | 对抗机制与黄霸体大体相近 | 眩晕（晕眩）及类似眩晕的强力控制技能可打断 |
| 黄霸体 | 同白霸体 | 同上 |
| 红霸体 | **不受任何控制效果影响**——眩晕、击飞、击退、点穴、定身等均无法打断红霸体状态下的动作 | 无法被打断 |

**战场定位**（汇编稿）：红霸体招式在对决和群战中优势极大，能无视敌方控制强行打出伤害或突进。

**扩充 · 白 / 黄霸体的携带与克制**

携带来源（汇编稿口径较笼统）：部分门派或江湖武学中的特定起手式、实招或怒招带黄霸体效果（例如某些套路中的收招或出招阶段）。

可打断 / 克制黄霸体的武学举例：

| 武学 | 招式 | 效果 |
|---|---|---|
| 古谱太极拳 | 部分招式 | 可眩晕黄霸体 |
| 青云掌法 / 蚀骨摧心掌 | 天雷震地 | 出招第一击可眩晕黄霸体（对未格挡目标有效） |
| 大力金刚指 | 一弹指顷 | 点穴定身，若未被招架可强行控制 |
| 雪斋剑法 | 寒心恨雪 | 附带僵直效果，可打断黄霸体 |

**扩充 · 红霸体武学举例**

- **落英飞花剑 / 风花雪月**（俗称"大风车"，君子堂或相关武学）：经典红霸体——释放无需积蓄怒气，伤害高，且可结合轻功。
- **雪斋剑法**：部分核心招式自带"无敌红霸体"。
- 其它各类古谱、镇派及江湖武学中带霸体标识的高阶实招 / 怒招。

## 九、防反

防反属于**架招类别**的招式，但和一般架招不同：

- 一般架招是一个**状态技能**：格挡成功后获得增益效果，或给对方负面效果。
- 防反则类似一种**【特殊气招】**：使用后你获得持续数秒的特殊状态，在对手使用**非虚招、非霸体类**招式攻击你时，你会迅速打断对手，并对其造成控制和伤害。
- 当然，虚招一样可以直接击破你的防反。
